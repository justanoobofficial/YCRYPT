# Security policy

YCRYPT is an early-stage personal project and has not received an independent security audit.

## Safe use

- Test only on copies of files first.
- Keep the original and a separate backup until decryption is tested.
- Use a strong passphrase and store it separately from encrypted files.
- Never send your passphrase to anyone.
- Report suspected vulnerabilities privately to the project maintainer rather than publishing details before a fix can be prepared.

## Scope

YCRYPT encrypts individual files. It is not a disk encryption system, secure erasure tool, or password recovery product.
